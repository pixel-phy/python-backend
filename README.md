## 📋 Temario completo (20 semanas)

### Semana 1: Variables, tipos y operadores ✅
| Tema | Contenido |
|------|-----------|
| Variables | `int`, `float`, `str`, `bool` |
| Entrada/Salida | `input()`, `print()`, f-strings |
| Conversiones | `int()`, `float()`, `str()`, `bool()` |
| Métodos de string | `strip()`, `lower()`, `upper()` |
| Manejo de errores | `try/except`, `raise` |

### Semana 2: Condicionales ✅
| Tema | Contenido |
|------|-----------|
| Condicionales básicos | `if`, `elif`, `else` |
| Operadores de comparación | `==`, `!=`, `<`, `>`, `<=`, `>=` |
| Operadores lógicos | `and`, `or`, `not` |
| Anidamiento | Condicionales dentro de condicionales |

### Semana 3: Bucles ✅
| Tema | Contenido |
|------|-----------|
| `while` | Bucle condicional |
| `for` | Bucle con `range()` |
| Control de bucles | `break`, `continue` |
| `else` en bucles | Ejecutar al terminar sin `break` |

### Semana 4: Strings ✅
| Tema | Contenido |
|------|-----------|
| Indexación | `[0]`, `[-1]` |
| Slicing | `[0:5]`, `[::2]`, `[::-1]` |
| Métodos | `upper()`, `lower()`, `strip()`, `split()`, `join()`, `find()`, `replace()`, `count()` |

### Semana 5: Listas ✅
| Tema | Contenido |
|------|-----------|
| Creación y acceso | `[1, 2, 3]`, `lista[0]` |
| Slicing | `[:3]`, `[1:]`, `[::-1]` |
| Métodos | `append()`, `insert()`, `remove()`, `pop()`, `index()`, `count()`, `sort()`, `reverse()` |
| Copia vs referencia | `.copy()`, `[:]` |
| List comprehension | `[n**2 for n in numeros if n%2==0]` |

### Semana 5.5: Listas (práctica extra) ✅
| Tema | Contenido |
|------|-----------|
| Matrices | Listas anidadas |
| Recorrido con `for` anidado | Sumas por filas y columnas |
| Proyecto integrador | Sistema de inventario, lista de compras |

### Semana 6: Pilas y Colas ✅
| Tema | Contenido |
|------|-----------|
| Pila (Stack) | LIFO con `append()` y `pop()` |
| Cola (Queue) | FIFO con `deque` y `popleft()` |
| Aplicaciones | Deshacer, historial navegador, fila banco |
| Dos pilas para cola | Simular FIFO con dos LIFO |

### Semana 7: Tuplas y Listas enlazadas ✅
| Tema | Contenido |
|------|-----------|
| Tuplas | Inmutabilidad, desempaquetado |
| Listas enlazadas | Nodos, punteros, recorrido |

### Semana 8: Conjuntos (sets) ✅
| Tema | Contenido |
|------|-----------|
| Sets | Elementos únicos |
| Operaciones | Unión (`|`), intersección (`&`), diferencia (`-`) |
| Métodos | `add()`, `remove()`, `frozenset()` |

### Semana 9: Diccionarios (dict) ✅
| Tema | Contenido |
|------|-----------|
| Creación | `{"clave": "valor"}` |
| Métodos | `keys()`, `values()`, `items()`, `get()`, `pop()` |
| Dict comprehension | `{x: x**2 for x in range(5)}` |

### Semana 10-11: Funciones ✅ 
| Tema | Contenido |
|------|-----------|
| Definición | `def funcion():` |
| Parámetros | Posicionales, nominales, por defecto |
| Retorno | `return` |
| Scope | `global`, `local` |
| `*args`, `**kwargs` | Argumentos variables |
| Lambda | Funciones anónimas |
| Recursividad | funciones que se llaman a sí mismas en su return |

### Semana 12: 🔄 Manejo de errores avanzado (en curso)
| Tema | Contenido |
