# 📚 Semana 6: Pilas y Colas (Stack y Queue)

## 🎯 Objetivo de la semana

Aprender dos estructuras de datos fundamentales en backend:
- **Pilas (Stack):** LIFO (Last In, First Out)
- **Colas (Queue):** FIFO (First In, First Out)

Estas estructuras son la base de sistemas que contienen historial de navegación, procesamiento de tareas, colas de mensajes, etc.

## 🔍 ¿Qué es una Pila (Stack)?

**Principio:** LIFO (Last In, First Out)  
**Último en entrar, primero en salir.**

Ejemplo real: Pila de platos, historial del navegador, botón "deshacer".

## 🔍 ¿Qué es una Cola (Queue)?
**Principio:** FIFO (First In, First Out)
**Primero en entrar, primero en salir.**
